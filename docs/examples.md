# Example notebooks

Start with the [self-contained quick start](getting-started.md), then use these
notebooks for longer workflows. Open them from a repository checkout in your
notebook environment with pytred installed.

| Notebook | Use it to |
| --- | --- |
| [Basic preprocessing](examples/01_basic_preprocessing.ipynb) | Define processing methods and assemble an output table. |
| [Precomputed tables](examples/02_use_completed_data.ipynb) | Reuse existing results through DataNode. |
| [Visualize a workflow](examples/03_visualize_workflow.ipynb) | Inspect a pipeline in a notebook. |

GitHub's notebook preview does not run the interactive graph. Use a trusted
notebook with JavaScript support, or try the [live viewer](tutorials/visualization.md#try-the-viewer).
